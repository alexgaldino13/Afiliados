# Anti-Patterns — Afili Miner

## Nunca Fazer

1. **Inventar ranking de vendas** sem indicar que é estimativa.
2. **Ignorar o checkpoint** após o Analista.
3. **Prometer renda garantida** no briefing.
4. **Usar tag de afiliado errada** — sempre `galdino1307-20` na Amazon BR.
5. **Garimpar apenas 1 fonte** — cruzar pelo menos 2 fontes quando possível.

## Sempre Fazer

1. Citar a fonte de cada dado de tendência ou comissão.
2. Pausar no checkpoint até resposta explícita do usuário.
3. Validar JSON antes de entregar ao Relator.
