# Quality Criteria — Afili Miner

## Garimpeiro

- [ ] Exatamente 5 produtos no JSON
- [ ] Cada item tem os 5 campos obrigatórios preenchidos
- [ ] URLs são públicas e acessíveis

## Analista

- [ ] Score 0–100 para todos os 5 produtos
- [ ] Pesos aplicados: 30/25/25/20
- [ ] Justificativa com no máximo 2 linhas por produto

## Checkpoint

- [ ] Top 3 exibido com nome, plataforma, score e URL

## Pomelli

- [ ] JSON com 4 campos: brand_voice, usp, market_gap, dores_avatar (array de 3)

## Estrategista

- [ ] Hook em 1 frase
- [ ] Canal recomendado com justificativa

## Relator

- [ ] Markdown + JSON válidos
- [ ] Tag Amazon presente quando aplicável
- [ ] Mínimo 3 próximos passos
